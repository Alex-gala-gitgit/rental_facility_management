# Third-party data notices

## Malaysia postcode data

The postcode dataset in `lib/data/malaysia_postcodes.dart` is generated from
[`acfatah/malaysia-postcodes-data`](https://github.com/acfatah/malaysia-postcodes-data),
which is distributed under the MIT License and derives its source records from
[`AsyrafHussin/malaysia-postcodes`](https://github.com/AsyrafHussin/malaysia-postcodes).

The generated file is bundled with the application so address selection works
offline on web, Android, and desktop builds.
